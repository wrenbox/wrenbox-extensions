# Captured store screenshots

Generated from the real, built extension by `npm run screens`
(`tests/screens/capture.spec.ts`), framed like the designed mockups in
`store-assets/`. 1280×800, ready to upload to the Chrome Web Store (and Edge
Add-ons) in this order:

1. `screenshot-1-before-after.png`
2. `screenshot-2-popup.png`
3. `screenshot-3-identify.png`
4. `screenshot-4-simulate.png`
5. `screenshot-5-settings.png`

Screenshot 1 shows both charts as a green-weak eye sees them: the page is
captured with Huefinch off and with Huefinch on (Green-weak, 80%), then the
Machado et al. deuteranopia simulation is applied to both, with the same maths
the extension uses. The other four are unmodified captures. Re-run after any
UI change.
