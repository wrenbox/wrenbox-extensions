## Attribution

Tracks in the YouTube Audio Library show either "Attribution not required" or a "Creative Commons" licence with the exact credit text to copy. The Mini Vandals' tracks in the library are normally marked **attribution not required**. This could not be checked from the build machine, because the library needs a signed-in YouTube account. **Owner: open the track in YouTube Studio → Audio Library and check its licence icon.**

- If it says **attribution not required**, no credit is needed. Crediting anyway is good practice and harmless.
- If it shows a **Creative Commons** licence, replace the line below with the exact text the library gives when you click the licence icon.

Credit line for the YouTube description:

```
Music: "Circuit Rush" by The Mini Vandals (YouTube Audio Library)
```

The YouTube Audio Library licence covers using the track in videos you upload to YouTube. That is how this video reaches the Chrome Web Store, whose promo video field takes a YouTube link. Check the library's terms before using the soundtrack anywhere else.

All sound effects in the video are synthesised in code (`tools/demo-video/audio.py`); no third-party samples are used.
